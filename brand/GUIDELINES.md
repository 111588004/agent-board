# Agent Board logo — usage guide

## The idea
The terminal prompt `>_`, built from two boards. The upper board is the person, the lower board is the agent, and the
underscore is the cursor. The person's board lies on top and the agent's board tucks under it with a clear gap: two
equal planes meeting at one point to make one prompt. It grows out of the `>_` icon the app header already uses.

## Files
| File | Use |
|---|---|
| `agent-board-icon.svg` | App icon, README badge, social avatar, npm. Mark on the ink tile. |
| `agent-board-favicon.svg` / `web/` | Browser tab and PWA icons (mark enlarged for 16–48 px). |
| `agent-board-symbol-light.svg` | Mark on white or light grey. |
| `agent-board-symbol-dark.svg` | Mark on ink or any dark background. |
| `agent-board-symbol-black.svg` / `-white.svg` / `-teal.svg` | One-colour: print, stamps, embossing, the teal brand surface (use white there). |
| `agent-board-lockup-light.svg` / `-dark.svg` | Horizontal lockup: site header, README title, slides. |
| `agent-board-lockup-stacked-light.svg` | Stacked lockup: square spaces, splash screens. |
| `agent-board-wordmark-light.svg` / `-dark.svg` | Wordmark alone, when the mark already appears nearby. |

All files are pure paths: no fonts, masks, filters or images. They were generated by `build.py` and `wordmark.py`
in `study/brand/v3/final/` (not in git); edit those and copy the output here.

## Colour
| Role | Light | Dark |
|---|---|---|
| Ink (person board, wordmark, tile) | `#0f1a24` | `#e7edf3` text / `#FFFFFF` mark |
| Teal (agent board, cursor) | `#0b6e8a` | `#4fc0dc` |

Same values as the homepage `:root` (`--ink`, `--accent`). Teal is the agent; never swap the two boards' colours.

## Type
Wordmark: IBM Plex Sans SemiBold, tracking −12/1000, outlined. Licence: SIL Open Font License 1.1.

## Clear space and minimum size
- Clear space on every side: the height of the cursor bar (the underscore).
- Minimum size: symbol 16 px (use the favicon file below 48 px); horizontal lockup 96 px wide.

## Don't
- Don't put the light symbol on teal or on black: use the white or dark version.
- Don't recolour the boards, add gradients, shadows or outlines, or rotate the mark (mirrored it becomes `<`).
- Don't redraw the wordmark in another font or set it as live text.
- Don't close the gap between the two boards; it is what tells person and agent apart in one colour.

## In the web UI
The board's **Brand** theme (header toggle, or `?theme=brand`) uses this palette and mark: `web/src/theme.jsx`,
`web/public/favicon-brand.svg`. **Classic** stays the default.
