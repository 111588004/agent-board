MCP · 0.4.4

讓 agent 自己管看板

接上 MCP 之後，你用平常講話的方式交代工作，Claude Code 或 Codex 會自己開單、改狀態、留進度。這頁說明怎麼接、它會做哪些事，以及它什麼時候會回頭問你。

接上 MCP

三步就接好。不需要先安裝 Agent Board，也不需要先開 server。

  1. 1

    貼一行設定

    $ claude mcp add \ agent-board …

    完整指令在下面，Claude Code、Codex、桌面版各一段，直接複製。

  2. 2

    確認連上了

    ❯ /mcp agent-board ✔ connected 10 tools

    開一個新的 session，輸入 /mcp。畫面為示意。

  3. 3

    第一次叫它做事

    agent-board: auto-started server (pid 48213)

    不是錯誤。server 在背景啟動，留給網頁看板、CLI 和其他 agent 共用。打開 localhost:4317 就看得到板子。

各家 agent 的設定

claude mcp add agent-board -s user -- npx -y @limao.li.design/agent-board mcp
# ~/.codex/config.toml
[mcp_servers.agent-board]
command = "npx"
args = ["-y", "@limao.li.design/agent-board", "mcp"]
startup_timeout_sec = 60   # 第一次要下載套件，約 20 秒
// ~/Library/Application Support/Claude/claude_desktop_config.json
{ "mcpServers": { "agent-board": {
    "command": "npx",
    "args": ["-y", "@limao.li.design/agent-board", "mcp"] } } }

這個方式還沒在桌面版實測過。從 Dock 開的 app 可能找不到用 nvm 裝的 npx，遇到時把 command 換成 which npx 印出的絕對路徑。

# server 要先開著（終端機跑 agent-board）
claude mcp add --transport http agent-board http://localhost:4317/mcp

HTTP 模式不會自動啟動 server。適合 server 一直開著、或 client 只吃網址的情況。

全貌：從一個看板到一張單

一層裝一層，跟資料夾一樣。

  • ▾Workspace個人
    • ▾Project專案管理PRJ
      • ▾TaskPRJ-3 確認場地與報價
        • SubtaskPRJ-4 比三家報價

Workspace 是一整個板子，Project 是一件事或一個 repo，Task 是一張卡，Subtask 是卡底下的小卡，也是最小單位。

agent 透過 MCP 可以增查改刪 Project 和 Task。Workspace 是你決定要開哪個板子，agent 工作時用不到，所以它只能指定用哪個板子，不能建立或刪除。

Subtask 也用同一組工具，多帶一個 parentId。

看板什麼時候會問你

看板對不上你的意思時，不會自己亂猜。它會依照「提問模式」決定：問你、自己挑一個並標上待確認，或直接回錯誤。切換下面的模式，看同一句話會走到哪裡。

你說「在專案開一張：確認場地報價」create_task(project: "專案")
「專案」這個詞
對得上一個專案嗎？
剛好一個
有標題嗎？
有
✓ 開單 PRJ-3 確認場地與報價

「對得上」依序比對：完全相同的專案名稱 → 你之前答過、被記住的別名 → 不分大小寫的名稱或前綴。建專案時沒給前綴也一樣：on、new 會問你，off 回錯誤，看板從不自己編前綴。

改模式

agent-board config ask new

或對 agent 說「把看板的提問改成只問新專案」（set_ask_mode）。CLI、MCP 和 Claude Code mod 共用同一個設定，改了立刻生效。

處理「待確認」

看板自己挑的卡會標 ⚠ 待確認。在網頁看板按 Confirm，或對 agent 說「PRJ-3 的專案沒錯」（update_task 帶 confirm）。

答錯了想重來

答過的詞會被記成別名。記錯了用 agent-board project forget 專案 取消。

疑難排解

Codex 說 MCP 啟動逾時
第一次執行要下載套件。把 startup_timeout_sec 調到 60。
工具回 connection refused
HTTP 模式不會自己開 server。在終端機跑 agent-board，或改用 stdio 設定。
想確認連到的是哪一個 server
打開 http://localhost:4317/api/meta，會看到版本、pid 和資料目錄。
想停掉背景的 server
用第一次呼叫時印出的 kill <pid>。
卡片的描述整段不見了
你可能說了「把描述改成…」，agent 用 update_task 帶 notes 整段覆蓋。只想補一句時說「記一下…」，它會用 add_task_note 追加一行，原本的內容不動。
