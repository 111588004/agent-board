什麼是 Claude Code mod？

mod 是 Claude Code 的一種外掛，用 JavaScript 或 TypeScript 寫成，直接跑在 Claude Code 裡面。它可以在輸入框上方畫東西、在每回合結束時做事，這些是 MCP 和一般 hooks 做不到的。Agent Board 的 mod 就是用這兩點：把目前接手的卡顯示出來，並在每回合自動回報。

看官方說明：Mods overview →

版本
終端機 2.1.287 以上，桌面版 Code 分頁 2.1.286 以上
預設
開啟。不想用時在 /plugin 停用
權限
mod 以你的身分執行，只裝信任的來源。這個 mod 只連你設定的看板網址

它做什麼：你照常工作，卡片自己長出紀錄

左邊是你的 Claude Code session，右邊是看板上同一張卡。你什麼都不用多打，mod 在這四個時間點替你寫進去。

你的 Claude Code session看板上的 PRJ-3
開 session
$ claude ▌ PRJ-3 ◐ in_progress 確認場地與報價
認領負責人改成 claude，填上目錄和分支
第 1 回合
❯ 比較三個場地 ⏺ 比了三個場地，兩個符合
[10:31 · claude] 比了三個場地，兩個符合 (2 Bash)
第 2 回合
❯ 整理報價表 ⏺ 報價表已存成 quotes.md
[10:48 · claude] 報價表已存成 quotes.md (edited 1 file)
關 session
❯ /exit
[11:02 · claude] claude session ended

卡片的狀態從頭到尾都沒變。打開 session 不代表開始做，關掉也不代表做完，所以 mod 不碰狀態，也不換負責人、不自己建卡。

安裝

  1. 1

    確認版本

    $ claude --version 2.1.292

    終端機要 2.1.287 以上，桌面版 Code 分頁 2.1.286 以上。版本太舊時 mod 不會載入，也不會報錯。

  2. 2

    安裝 mod

    ❯ /plugin install agent-board@…

    在 Claude Code 裡貼下面三行。

  3. 3

    綁一張卡

    ❯ /board-sync new "修登入頁"

    建卡並綁定目前的目錄和分支。已經有卡就打 /board-sync link PRJ-3。

/plugin marketplace add 111588004/agent-board
/plugin install agent-board@agent-board-mods
/reload-plugins

只想試一個 session：在 repo 目錄下跑 claude --plugin-dir mods/agent-board。

輸入框上方那一行

綁定卡片後，輸入框上方會一直留著一行，跟著你的主題配色。從左到右是這些欄位：

▌ PRJ-3卡號 ◐ in_progress狀態 ▲ high優先度 確認場地與報價標題 claude負責人 ⎇ feat/venue分支 3 notesnote 數

終端機太窄時會從右邊開始收起來。這一行是快照，有人在網頁上移動卡片，下一回合結束才會更新。

需要你處理的時候

等你決定綁哪張卡mod 不會替你選，也不會自己建卡
▌ ? no card for this branch → /board-sync new | link <ID>

這個分支沒有卡。new 開一張，或 link 綁現有的。

▌ ≡ 3 cards match: PRJ-1 PRJ-4 PRJ-7 → /board-sync link <ID>

好幾張卡都對得上。用 link 選一張。

▌ ⊘ PRJ-3 is held by codex → /board-sync link PRJ-3 to take over

卡在別的 agent 手上。真的要接手才打 link。

看板沒在跑重開 agent-board 就會接回來
▌ ✗ board offline → PRJ-3 last known, retrying

綁好之後 server 停了，會自己重試。

/board-sync 指令

指令做什麼
/board-sync目前狀況：開關、server、綁的卡、下一步。這個 repo 還沒有專案時會問你。
new ["標題"]建一張卡（進行中、claude、目前目錄和分支）並綁定。沒給標題會給你選：對話第一句或分支名。
link <ID>綁定並認領這張卡，把目錄和分支寫回卡上，記住這個 repo 對應的專案。
open在瀏覽器打開綁定的卡，沒綁就開看板。
status跟不帶參數一樣，但不問問題、不發請求。
on / off開關回報。off 的範圍看 offScope 設定。
ask [on|new|off]看板的提問模式，跟 MCP 的 set_ask_mode 是同一個設定（見 MCP 指南）。

設定

在 /config 裡改。大多數人不用動。

選項預設說明
enabledtrue總開關。
agentBoardUrlserver 網址。空的話用 AGENT_BOARD_URL，再來是 localhost:4317。
workspace要寫到哪個 workspace。
projectnew 開卡用的專案。空的話用這個 repo 上次綁的專案，再來是跟資料夾同名的專案，都沒有就問你。
offScopesessionoff 的範圍：本 session、本 repo，或全部。

已知限制

對話框多出來的選項
Claude Code 的選項對話框一定會附「Type something」和「Chat about this」，mod 無法隱藏。選它們一律當成取消。
server 卡住不回
每次請求最多等 1.5 秒，失敗後 15 秒內不再發請求，之後加倍，最長 10 分鐘。server 沒開則立刻失敗，不會拖慢 session。
worktree 要用絕對路徑
卡上的 worktree 不會展開 ~。
還沒驗證
淺色主題、把符號畫成兩格寬的終端機、真實中文字型下的寬度。
